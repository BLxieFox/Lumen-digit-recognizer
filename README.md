# Lumen — 手写数字识别

> **从零实现的 NumPy 神经网络 + Web 手写板，完全离线，识别你写下的每一个数字。**

[![Python](https://img.shields.io/badge/Python-3.8%2B-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](#许可证)
[![Offline](https://img.shields.io/badge/运行-完全离线-orange.svg)](#离线与自包含)
[![No Framework](https://img.shields.io/badge/神经网络-纯%20NumPy%20从零实现-9cf.svg)](#工作原理)

「Lumen」是光通量的单位「流明」，寓意数字在暗室中借由琥珀色的「磷光」显形——正如这款应用的视觉风格：一座暗室中的科学仪器。

它不依赖 PyTorch / TensorFlow，神经网络的每一行前向传播与反向传播都由 NumPy 手写而成；通过浏览器里的手写板画一个数字，模型即可在本地毫秒级给出识别结果与逐类概率，并把完整的处理日志实时流式推送到页面里。

---

## ✨ 特性

- **手写板交互**：Canvas 手写板，支持画笔粗细调节、单笔撤销、一键清空、抬手自动识别。
- **从零实现的神经网络**：纯 NumPy 实现多层感知机（MLP），无任何深度学习框架依赖。
- **实时日志流**：通过 SSE（Server-Sent Events）将后端处理日志实时推送到页面，每一步预处理与推理都可见。
- **可调参数**：去噪阈值、温度缩放、Top-K、置信度阈值、中心化 / 尺寸归一化等一应俱全。
- **完全离线**：数据集、模型权重、依赖均本地化，运行与推理不联网。
- **美观简洁的界面**：暗色「科学仪器」主题，暖纸张手写板，琥珀色磷光强调。

## 🧠 工作原理

Lumen 的核心是一套经典的 **全连接前馈神经网络（MLP）**，配合 **MNIST 风格的手写预处理管线**。

### 1. 神经网络结构

```
输入层 (784)  →  隐藏层 (128)  →  隐藏层 (64)  →  输出层 (10)
   28×28         ReLU            ReLU           Softmax
```

- **架构**：`[784, 128, 64, 10]`，共 **109,386** 个可训练参数。
- **参数初始化**：He 初始化（`√(2 / fan_in)`），适配 ReLU 激活，避免梯度消失。
- **隐藏层激活**：ReLU `f(z) = max(0, z)`。
- **输出层激活**：Softmax，将 logits 映射为 10 个类别的概率分布。
- **损失函数**：交叉熵损失，与 Softmax 组合后反向传播梯度退化为简洁的 `δ = p̂ − y`。
- **优化器**：带动量（momentum = 0.9）的小批量随机梯度下降（SGD）。

### 2. 手写图像的预处理管线

手写板的笔画与 MNIST 训练数据之间存在尺度、位置差异，因此推理前会做一次标准化：

```
112×112 原始墨迹
   │  ① 最大池化下采样（保留细笔画）
   ▼
 28×28 灰度强度
   │  ② 阈值去噪（滤除浅淡噪声）
   ▼
 28×28 去噪后
   │  ③ 包围盒中心化（按墨迹重心裁剪）
   ▼
   N×N 紧凑区域
   │  ④ 尺寸归一化到 20×20 并居中（MNIST 标准）
   ▼
 28×28 输入张量 → 数值归一化 → 送入网络
```

这套流程让任意大小、任意位置的书写都能被规整到模型「熟悉的形态」，是识别鲁棒性的关键。

### 3. 温度缩放（Temperature Scaling）

推理时可调节温度 `T`，对 logits 做缩放后再做 Softmax：

```
pᵢ = exp(zᵢ / T) / Σⱼ exp(zⱼ / T)
```

- `T < 1`：分布更尖锐，模型更「自信」，突出最高概率类别。
- `T > 1`：分布更平滑，能观察到次优类别的概率（便于理解模型的「犹豫」）。

## 🚀 快速开始

### 环境要求

- Python **3.8+**（开发环境为 3.12）
- 依赖：`numpy` 与 `flask`

### 1. 获取代码

```bash
git clone https://github.com/<你的用户名>/lumen.git
cd lumen
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

> 项目已内置 `vendor/` 目录实现离线自包含；若需干净安装，可在删除 `vendor/` 后重新执行上述命令。

### 3. 启动服务

```bash
python app.py            # 默认 http://127.0.0.1:8000
python app.py --port 5000
```

浏览器打开 **http://127.0.0.1:8000/**，即可在手写板上书写数字。

> 若提示缺少模型权重，请先运行一次训练：`python train.py`。

## 🖥️ 使用方法

1. **书写**：在左侧手写板用鼠标或触控笔写下 0–9 的一个数字。
2. **识别**：默认「抬手自动识别」开启，松手后右侧即时显示识别数字、置信度与 Top-K 概率条形图。
3. **日志**：页面底部的日志面板实时展示后端的每一步预处理与推理过程。

### 可调设置

| 分组 | 设置项 | 默认值 | 说明 |
|------|--------|--------|------|
| 预处理 | 中心化 | 开 | 按墨迹包围盒裁剪，消除位置偏移 |
| 预处理 | 尺寸归一化 | 开 | 缩放至 20×20 并居中（MNIST 标准） |
| 预处理 | 去噪阈值 | 0.15 | 过滤低于该强度的噪声像素 |
| 推理 | 温度 T | 1.0 | 控制概率分布的尖锐程度（0.2–5.0） |
| 推理 | 显示 Top-K | 5 | 概率条形图显示前 K 个类别 |
| 推理 | 置信度阈值 | 0.50 | 低于该值的结果标为「不确定」 |
| 交互 | 抬手自动识别 | 开 | 松手后自动触发预测 |
| 画笔 | 粗细 | 26 | 手写笔画宽度（6–44） |

## 🔧 技术文档

### 后端 API

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/` | 返回 Web UI 页面 |
| `GET` | `/status` | 返回模型加载状态、架构、参数量 |
| `POST` | `/predict` | 接收手写图像 + 设置，返回识别结果 |
| `GET` | `/logs` | SSE 流，实时推送后端日志 |

#### `POST /predict` 请求示例

```json
{
  "image": [[0.0, 0.0, "... 112×112 的墨迹强度数组 ..."]],
  "settings": {
    "center": true,
    "normalize": true,
    "threshold": 0.15,
    "temperature": 1.0,
    "top_k": 5
  }
}
```

#### 响应示例

```json
{
  "ok": true,
  "digit": 7,
  "confidence": 0.9876,
  "probabilities": [
    { "digit": 7, "prob": 0.9876 },
    { "digit": 2, "prob": 0.0088 }
  ],
  "elapsed_ms": 0.42
}
```

### 核心模块

- **`network.py`**：`MLP` 类实现了 `forward`（前向传播）、`_backprop`（反向传播）、`train_step`（动量 SGD）、`save` / `load`（`.npz` 持久化），以及 `softmax`、`relu` 等基础算子。
- **`train.py`**：负责下载 MNIST、解析 IDX 格式、数据归一化、训练循环与准确率评估。
- **`app.py`**：`EventLog` 线程安全日志中心支撑 SSE 推送；`preprocess()` 实现完整的标准化管线；`predict()` 路由完成推理与温度缩放。

## 📦 离线与自包含

本项目按「离线优先」设计：

- **数据集**：MNIST 首次训练时下载，之后缓存于 `data/`，永不联网。
- **模型权重**：训练后保存于 `model/mnist_mlp.npz`，推理时直接加载。
- **依赖**：`vendor/` 通过 `pip install --target vendor numpy flask` 生成，可将 Python 运行时完全本地化。

> **发布提示**：`vendor/`、`data/`、`model/` 体积较大且均可重新生成，建议在 `.gitignore` 中忽略；仅在需要「开箱即离线」的分发包中才打包它们。

## 🧪 重新训练

```bash
python train.py                              # 默认 10 epoch, batch 64, lr 0.1
python train.py --epochs 15 --batch 128 --lr 0.05
```

训练完成后权重自动覆盖 `model/mnist_mlp.npz`，重新启动服务即可生效。
